# Editra Roadmap

## Planned

- Standards-based Clipboard API enhancements.
- Optional CRDT transport adapters and presence servers.
- DOCX package import/export with higher native Word fidelity.
- Accessible screen-reader announcements for complex table operations.
- Pagination-aware widow/orphan controls.
- Footnotes, endnotes, citations, and bibliography management.
- Automated cross-browser visual regression coverage.
- Language packs and right-to-left layout tools.

## Under consideration

- Offline-first document storage.
- Pluggable spell-check providers.
- Template marketplace and reusable content blocks.
- Mobile-optimized contextual toolbar.

Roadmap items are proposals, not commitments. Approved work must be documented in the user guide and release notes when released.
